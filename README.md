# 客户自媒体反诈微舆情监测工具

> 内部使用的舆情监测小工具，主要用于监控各平台关于反诈关停的投诉内容

## 这是干嘛的

简单说就是：用户号码被反诈模型关停后，可能会去微博、知乎、贴吧这些地方发帖投诉。我们这个工具就是自动去搜这些内容，然后分个级，方便内部处理。

目前能监测的平台：
- 微博 ✅
- 知乎 ✅ 
- 百度贴吧 ✅
- 抖音（框架写好了，需要接第三方数据）
- 小红书（同上）
- 快手（同上）

## 怎么用

### 1. 装环境

```bash
# 克隆下来
git clone https://github.com/N-E-C/anti-fraud-monitor.git
cd anti-fraud-monitor

# 建个虚拟环境
python -m venv .venv
source .venv/bin/activate

# 装依赖
pip install -r requirements.txt
```

### 2. 配置

```bash
# 复制配置文件
cp .env.example .env

# 编辑 .env，填入各平台的Cookie（微博和知乎需要）
# WEIBO_COOKIE=你的cookie
# ZHIHU_COOKIE=你的cookie
```

关键词配置在 `config/keywords.yaml`，可以自己加减。

### 3. 跑起来

```bash
# 初始化数据库（第一次用要跑这个）
python main.py initdb

# 先试一次，看能不能跑通
python main.py crawl

# 长期运行的话用这个，会定时自动抓取
python main.py start

# 导出今天的报表
python main.py report
```

## 风险分级逻辑

内容会根据关键词和情感自动分级：

- **高风险** 🔴：直接投诉、提到工信部、要维权的
- **中风险** 🟡：质疑停机原因、表示不满的
- **低风险** 🟢：只是提了一下反诈、中性讨论的

还会尝试识别是不是诈骗用户在用舆论施压（比如"集体投诉运营商"这种）

## 报表

每天会自动生成Excel报表，放在 `reports/output/` 下面，里面有4个sheet：
- 综合概览（汇总数据）
- 高风险明细（重点关注的）
- 全量数据
- 用户核查清单（提取出的手机号，方便查关停记录）

## 关于新平台（抖音/小红书/快手）

代码框架已经写好了，但这些平台反爬比较厉害，没有公开的搜索API。要用的话需要：

1. **方案1**：买第三方数据平台的接口（蝉妈妈、飞瓜之类的）
2. **方案2**：申请官方开放平台权限（门槛比较高）
3. **方案3**：用RSS监控或者关键词订阅服务

有需要的话找我配。

## 一些注意事项

- 微博和知乎需要配置Cookie，Cookie过期了要重新登录拿
- 抓取频率别太激进，容易被封
- 手机号在数据库里是脱敏存储的
- 数据仅供内部使用，不要外传
